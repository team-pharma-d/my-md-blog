# tags の運用ルール

記事の `tags`（frontmatter）で、表記ゆれを防ぎ、将来のタグ別一覧ページを作りやすくするためのルール。

## ルール

1. **1記事あたり最大3個**まで
2. **英字は、公式の表記に合わせる**（例：`Next.js`、`TypeScript`、`Markdown`）。同じ意味のタグは、表記を1つに統一する（`nextjs` と `Next.js` を混在させない）
3. **日本語は、一般的な表記を1つに決める**（例：`デプロイ`。`deploy` と混在させない）
4. **記事の主題を表すものだけ**を付ける。`Next.js` のように全記事に付くものは、必要最小限にとどめる
5. 新しいタグを使うときは、下の「使用中のタグ」を確認し、近いものがあればそれを使う

## 使用中のタグ

| タグ | 使う記事の例 |
|---|---|
| Next.js | 全般 |
| SSG | はじめてのSSG |
| Markdown | markdown の基本、見出しとコードブロックの書き方サンプル |
| frontmatter | frontmatter とは |
| ハイライト | コードハイライトの仕組み、見出しとコードブロックの書き方サンプル |
| デプロイ | Vercel にデプロイする |

## 対応履歴

作成時に、小文字・英語表記のタグが混在していた記事を、上のルールに合わせて修正した（**対応済み**）。

| 修正前 | 修正後 | 状態 |
|---|---|---|
| `markdown` | `Markdown` | 対応済み |
| `highlight` | `ハイライト` | 対応済み |
| `deploy` | `デプロイ` | 対応済み |

新しい記事を追加するときは、「使用中のタグ」の表を更新する。
