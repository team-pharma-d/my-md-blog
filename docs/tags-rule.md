# tags の運用ルール

記事の `tags`（frontmatter）で、表記ゆれを防ぎ、将来のタグ別一覧ページを作りやすくするためのルール。

## ルール

1. **1記事あたり最大3個**まで
2. **英字は、公式の表記に合わせる**（例：`Next.js`、`TypeScript`、`Markdown`）。同じ意味のタグは、表記を1つに統一する（`nextjs` と `Next.js` を混在させない）
3. **日本語は、一般的な表記を1つに決める**（例：`デプロイ`。`deploy` と混在させない）
4. **記事の主題を表すものだけ**を付ける。`Next.js` のように全記事に付くものは、必要最小限にとどめる
5. 新しいタグを使うときは、下の「使用中のタグ」を確認し、近いものがあればそれを使う

## 使用中のタグ

| タグ | 使う記事の例 |
|---|---|
| Next.js | 全般 |
| SSG | はじめてのSSG |
| Markdown | markdown の基本 |
| frontmatter | frontmatter とは |
| ハイライト | コードハイライトの仕組み |
| デプロイ | Vercel にデプロイする |

## 現状との差分（要修正）

現在の記事は、`markdown`、`highlight`、`deploy` のように小文字・英語表記のタグが混在している。上のルールに合わせて、次のように直す。

| 現在 | 修正後 |
|---|---|
| `markdown` | `Markdown` |
| `highlight` | `ハイライト` |
| `deploy` | `デプロイ` |
